# Database Setup (Updated)

Summary

High-level steps to prepare a PostgreSQL database (or Supabase) for the project. See `Backend/config.py` for expected env variables.

Quick steps

1. Create Postgres DB and user
2. Set `DATABASE_URL` in `Backend/.env`
3. Run `Backend/scripts/create_tables.py` to create required tables

Environment variables

- `DATABASE_URL`
